# AeroSphere — социальная сеть в стиле Frutiger Aero

Прототип социальной сети, вдохновлённый эстетикой **Frutiger Aero**: глянцевые поверхности, стеклянные панели, природные мотивы и оптимистичная атмосфера.

## 🚀 Запуск

Просто откройте `index.html` в любом современном браузере. Никаких зависимостей и серверов не требуется.

## 📁 Структура

- `index.html` — разметка всех разделов
- `style.css` — стили, включая адаптивность и эффекты стекла
- `script.js` — логика переключения вкладок, создания постов, лайков

## ✨ Возможности

- Адаптивный дизайн (десктоп с боковой панелью, мобильный с нижней навигацией)
- Разделы: Главная, Профиль, Музыка, Друзья, Сообщения, Настройки
- Создание и публикация постов
- Лайки с анимацией
- Смена цветовой темы
- Стеклянные панели (backdrop-filter)
- Шрифт Nunito для дружелюбного вида

## 📦 Как упаковать в zip

1. Создайте папку `aero-sphere`.
2. Скопируйте в неё все четыре файла (`index.html`, `style.css`, `script.js`, `README.md`).
3. Заархивируйте папку: правой кнопкой → «Отправить» → «Сжатая ZIP-папка» (Windows) или используйте команду `zip -r aero-sphere.zip aero-sphere/` (Linux/macOS).
